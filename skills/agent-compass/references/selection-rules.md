# Selection and placement

Use exact target IDs. Include common, the actual harness, exact model, and an
explicitly adopted framework only. A family is a separate explicit target,
not inherited by every model. A missing model or record means unknown.
Do not assume compatibility from shared brand names or provider aliases.

Recommended and conditional practices are candidates within their scope.
Candidate, discouraged, deprecated, superseded and unverified statuses are
not automatic standing instructions. Mixed or contradicted local evaluations
require judgment. Conditional guidance must retain its conditions.

- instruction: candidate behavior text; preserve project constraints.
- configuration: API, runtime, permissions or integration advice; not
  executable settings or a grant of authority.
- author-guidance: advice for the person or agent drafting instructions.
- unclassified: no automatic insertion into a draft.

Do not replace existing AGENTS.md with a generic draft. Review the actual
project context. Avoid unnecessary procedural duplication and repeat reviews,
while preserving necessary safety checks. If the requested task is analysis,
report findings and do not apply changes.
